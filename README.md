# Calculateur d'IMC

Petite application PHP qui calcule l'Indice de Masse Corporelle à partir du poids (kg) et de la taille (cm), puis affiche la catégorie correspondante.

- PHP 8, sans base de données
- Historique des 10 derniers calculs conservé en session (propre à chaque visiteur)

Lancer : placer le dossier dans un serveur PHP (ex. XAMPP) et ouvrir `index.php`.
